# Cellarity

> Cellarity is a clinical-stage biotechnology company in Somerville, Massachusetts, founded in 2017 inside Flagship Labs by Flagship Pioneering. It discovers medicines against the cell as a whole rather than a single molecular target, using a multi-omics AI platform trained on tens of millions of single-cell transcriptomes. Lead program CLY-124 is a first-in-class globin-switching oral medicine for sickle cell disease in Phase 1.

IMPORTANT PROVENANCE: Cellarity does not publish an llms.txt. This file was GENERATED by API Evangelist on 2026-08-09 from the artifacts in this repository and from live probes of cellarity.com. https://cellarity.com/llms.txt returns 404.

Cellarity publishes NO product API, NO developer portal, NO SDK and NO developer documentation. The only anonymously readable machine-readable surface on cellarity.com is the WordPress REST API that backs the marketing site. Do not describe Cellarity as an API provider.

## APIs

- [Cellarity Content API (WordPress REST wp/v2)](https://cellarity.com/wp-json/wp/v2): The CMS content API behind cellarity.com — news items, drug-development pipeline, team profiles, event speakers, case studies, videos, pages, media and site search. 167 operations across 55 paths. Anonymous reads; writes require WordPress Application Passwords over HTTP Basic. This is not a Cellarity product API.

## Key operations

- `listNewsItems` — GET /wp/v2/news_item (48 records). Filter by the `article-type` taxonomy: news, press, publication, presentation, media, ext.
- `listPipelineItems` — GET /wp/v2/pipeline-item (6 records). CLY-124, Myelofibrosis, Exploratory Hematology, MASH, In Development.
- `listTeamMembers` — GET /wp/v2/team-member (19 records) with `team-category`: management, board, founders.
- `listEventSpeakers` — GET /wp/v2/event-speaker (11 records).
- `search` — GET /wp/v2/search. The only cross-entity operation.
- `getRouteIndex` — GET /wp-json/. Full route descriptor with per-parameter types, enums and defaults.

## Open source

- [github.com/Cellarity](https://github.com/Cellarity): Four public research repositories.
- [DrugReflector](https://github.com/Cellarity/drugreflector): Compound ranking from gene expression signatures using ensemble neural networks. Not on PyPI despite the README's pip instruction.
- [DILImap](https://github.com/Cellarity/DILImap): Predicting drug-induced liver injury from transcriptomics. Published on PyPI as `DILImap` 1.0.5.
- [MolRL](https://github.com/Cellarity/MolRL): Targeted molecular generation with latent reinforcement learning.

## Not available

- No OpenAPI published by Cellarity, no developer portal, no API reference, no getting-started guide.
- No SDK or API client library in any language.
- No MCP server. The `wp-abilities/v1` registry exists but returns 401 anonymously and no MCP namespace is registered.
- No A2A agent card at /.well-known/agent-card.json or /.well-known/agent.json on any host.
- No webhooks, no events, no AsyncAPI.
- No OAuth, no OpenID Connect, no scopes.
- No security.txt, no vulnerability-disclosure program, no trust center, no published certifications.
- No status page, no SLA, no API changelog, no deprecation policy.
- No RSS feed — https://cellarity.com/feed/ 301-redirects to the homepage.
- docs.cellarity.com is a private Read the Docs Business instance; every path redirects to SSO login.
